# 출석 체크 웹 앱 (Google Apps Script)

이 패키지는 제공된 출석부 구조를 기준으로 만든 웹 앱입니다.

## 기능
- 참가자가 이름 + 휴대폰 번호 뒤 4자리로 확인
- 참가자 명단의 조 번호/공동체를 표시
- `1주차` 열(I열)에 한국 시간 기준 출석 시각 기록
- 같은 사람이 다시 등록하면 기존 시간을 새 시간으로 덮어씀
- 관리자 로그인 후 참가자/출석 현황 조회
- 관리자 페이지에서 원본 Google 스프레드시트를 Excel(.xlsx)로 다운로드

## 스프레드시트 열 구조
기본 코드는 다음 열을 사용합니다.
- B열: 조 (조별 병합 셀을 자동으로 이어서 읽음)
- C열: 공동체
- D열: 이름
- G열: 연락처
- I열: 1주차 출석 시간
- 2행: 열 제목, 3행부터 참가자 데이터

업로드한 엑셀 파일은 E/F열의 제목과 데이터가 서로 뒤바뀐 것처럼 보입니다(제목은 E=생년월일, F=성별이지만 데이터는 E=성별, F=생년월일). 이 웹 앱은 해당 열을 읽지 않으므로 출석 처리에는 영향이 없습니다.

## 설치 및 배포

1. 대상 Google 스프레드시트를 열고 주소에서 `/d/`와 `/edit` 사이의 ID를 확인합니다.
2. https://script.google.com 에서 새 프로젝트를 만듭니다.
3. 기본 `Code.gs` 내용을 이 패키지의 `Code.gs`로 바꿉니다.
4. `+` → HTML을 선택하고 파일 이름을 정확히 `Index`로 만든 다음, `Index.html` 내용을 붙여넣습니다. HTML 파일 이름은 확장자를 제외하고 `Index`여야 합니다.
5. 프로젝트 설정(톱니바퀴)에서 **스크립트 속성**에 다음 두 항목을 추가합니다.
   - `SPREADSHEET_ID` = `1iMaD6Qsfri2y_8d51i3OzWOIAek6uFX_` (공유해 주신 링크의 ID)
   - `ADMIN_PASSWORD` = `880704` (원하면 더 강한 비밀번호로 변경 권장)
6. `appsscript.json` 매니페스트를 편집할 수 있도록 프로젝트 설정에서 “appsscript.json 매니페스트 파일을 편집기에 표시”를 켜고, 이 패키지의 `appsscript.json` 내용으로 바꿉니다.
7. 편집기에서 `doGet`을 실행하지 말고 **배포 → 새 배포 → 유형 선택(톱니바퀴) → 웹 앱**으로 배포합니다.
8. **다음 사용자 권한으로 실행: 나**를 선택합니다. 접속 가능한 사용자는 참가자가 Google 계정에 로그인하지 않아도 되도록 설정하려면 조직/계정 정책에 맞는 공개 접근 옵션을 선택합니다.
9. 배포를 누르고 권한 요청을 승인한 뒤, 생성된 웹 앱 URL을 참가자에게 공유합니다.
10. 코드를 수정한 경우 **배포 관리 → 수정(연필) → 새 버전**으로 업데이트해야 배포된 앱에 반영됩니다.

## 보안 안내
- 참가자 페이지는 공개 접근일 수 있으므로 URL을 가진 사용자가 출석을 시도할 수 있습니다.
- 관리자 비밀번호는 스크립트 속성에 저장되어 화면 코드에 노출되지 않습니다. 다만 짧은 숫자 비밀번호는 추측될 수 있으므로 실제 운영 전 더 강한 비밀번호를 권장합니다.
- 앱은 참가자 검색 결과로 이름/조/공동체만 반환하며, 전체 연락처는 관리자 페이지에서만 보여줍니다.
- 웹 앱을 배포하는 Google 계정은 해당 스프레드시트에 편집 권한이 있어야 합니다.
- 이 앱은 기존 Google 스프레드시트의 `Sheet1`(없으면 첫 번째 시트)을 사용합니다. 시트 이름이 다르면 `getSheet_()`에서 지정해 주세요.
- 코드가 기존 시트의 I열에 시간을 기록합니다. I열이 실제로 `1주차`인지 확인하고 배포하세요.
